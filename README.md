# Callaway Legal

One-page static website ready for GitHub Pages. Upload every file in this folder directly to the repository root.

## Before publishing

- Replace the name and portrait unless authorized for public use.
- Add only verified attorney credentials, admissions, contact details, and office information.
- Connect the contact form to a secure delivery service; it currently displays a setup notice and sends nothing.
- Review the privacy page and disclaimer for the relevant jurisdiction.

## GitHub Pages

Open **Settings → Pages**. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then save. The site normally appears at `https://USERNAME.github.io/REPOSITORY/` after deployment completes.
